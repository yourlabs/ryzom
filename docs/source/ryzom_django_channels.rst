ryzom_django_channels package
=============================

Reactivity layer: subscriptions, facets, DDP push and polling. These modules
were previously documented under ``ryzom.*`` (``ryzom.consumers``,
``ryzom.ddp``, ``ryzom.signals`` …); they now live in ``ryzom_django_channels``.
